# Intake binder fonts

Latin subsets of the typefaces used by the Northlake intake binder
(`render_intake_package.py`), embedded into the generated HTML so it renders the
same offline and in print.

| File | Face |
| --- | --- |
| `Spectral-SemiBold-latin.woff2` | Spectral SemiBold, headings and the wordmark |
| `IBMPlexSans-Variable-latin.woff2` | IBM Plex Sans, weights 100 to 700 |
| `IBMPlexSans-Italic-latin.woff2` | IBM Plex Sans Italic |
| `IBMPlexMono-Medium-latin.woff2` | IBM Plex Mono Medium |
| `IBMPlexMono-SemiBold-latin.woff2` | IBM Plex Mono SemiBold |

Both families are licensed under the SIL Open Font License 1.1; see
`OFL-Spectral.txt` and `OFL-IBMPlex.txt`. Characters outside the Latin subset fall
back to system fonts.
