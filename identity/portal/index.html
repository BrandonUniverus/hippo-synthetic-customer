Session handoff

How the repeat login works

  1. 01

    Authenticate with Northlake

    Keycloak validates the user and creates the provider's browser session.

  2. 02

    Choose Northlake in EnergyHippo

    EnergyHippo starts its selected OIDC authorization request or SAML AuthnRequest and owns the complete callback validation.

  3. 03

    Return without another password

    Northlake reuses its SSO session, then returns either OIDC tokens or a signed SAML response to the registered callback.

This page never handles passwords or tokens. It only links the real identity provider to the relying application's own login flow.

SAML 2.0 provider ready

Northlake is ready for the EnergyHippo service provider.

Keycloak returns a persistent NameID and the Northlake attribute set in an HTTP-POST response. Both the outer response and assertion are signed with RSA-SHA256; the focused verifier checks signatures, issuer, audience, destination, recipient, time bounds, request correlation, replay resistance, logout, and disabled users.
