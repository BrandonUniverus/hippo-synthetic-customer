SAML 2.0 provider

          

            Keycloak returns a persistent NameID and the Northlake attribute set in an
            HTTP-POST response. Both the response and the assertion are signed with
            RSA-SHA256; the focused verifier checks signatures, issuer, audience,
            destination, recipient, time bounds, request correlation, replay
            resistance, logout and disabled users.

            opens the user's home page: it treats any RelayState as its own handle, so
            this path cannot land on a specific page.
