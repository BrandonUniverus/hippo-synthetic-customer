Phase 8 · SCIM and cross-protocol lifecycle

Provision EnergyHippo without turning Keycloak into SCIM.

Northlake acts like a customer's provisioning client. EnergyHippo remains the SCIM service provider, while Keycloak independently proves OIDC or SAML authentication. Connection secrets stay in ignored runtime state and never appear in this page's API responses or evidence files.

Run one deterministic User and Group sequence

The runner creates or reconciles one synthetic User, proves filtering and PUT/PATCH, deactivates and reactivates it, and removes then restores one sanctioned Group membership. It leaves the User active and membership present.

Choose “User only” when Group capability is intentionally disabled.
