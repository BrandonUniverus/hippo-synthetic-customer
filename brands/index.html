Northlake brand systems

Northlake University and the six organisations that serve it. Each one is a folder here: tokens.css (colours, type, spacing, corners, logo use), fonts.css with its self-hosted fonts, and logo.svg, logo-reversed.svg and mark.svg. Every brand uses the same token names, so a page written once changes its whole look when it loads another brand's files.

Edit a tokens.css and refresh to see it below. After changing lettering or fonts, run python brands/tools/build_logos.py. See brands/README.md.
